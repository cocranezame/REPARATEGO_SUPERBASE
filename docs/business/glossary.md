# Glosario — ReparaTego

| Término | Definición |
|---------|-----------|
| **Tenant** | Empresa/negocio que usa el sistema. Aísla datos entre empresas. |
| **Sucursal** | Local físico del negocio donde se atiende. |
| **Orden de Servicio (OS)** | Documento que registra la recepción de un equipo para reparación. |
| **Diagnóstico** | Evaluación técnica del equipo recibido. |
| **Cotización de Compra** | Solicitud de precio enviada a un proveedor para comprar repuestos. |
| **Orden de Compra (OC)** | Compra confirmada a un proveedor. |
| **Cotización de Venta** | Presupuesto enviado a un cliente para un servicio o producto. |
| **Venta** | Transacción de venta de producto o servicio a un cliente. |
| **Domicilio** | Servicio técnico realizado en la ubicación del cliente. |
| **Movimiento de Stock** | Registro de entrada, salida, ajuste o transferencia de inventario. |
| **IGV** | Impuesto General a las Ventas (18% en Perú). |
| **RUC** | Registro Único de Contribuyentes (identificador tributario peruano). |
| **DNI** | Documento Nacional de Identidad (Perú). |
| **CE** | Carné de Extranjería. |
| **SUNAT** | Superintendencia Nacional de Aduanas y de Administración Tributaria. |
| **RLS** | Row Level Security — seguridad a nivel de fila en PostgreSQL. |
| **Feature Flag** | Configuración que permite habilitar/deshabilitar funcionalidades. |
