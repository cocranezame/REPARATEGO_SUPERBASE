# Web — Catálogos

> Pantalla unificada de catálogos maestros.
> Épica: E2

## Pantallas

### Catálogos (`/catalogos`)
- **Tabs:** Categorías | Componentes | Marcas | Modelos
- Cada tab tiene su tabla con búsqueda y CRUD inline o modal

#### Tab Categorías
- Tabla jerárquica (tree/accordion) mostrando padre → hijos
- Crear/editar con selector de categoría padre

#### Tab Componentes
- Tabla con filtro por categoría (cascada)
- Crear/editar con selector de categoría

#### Tab Marcas
- Tabla simple con logo, nombre
- Crear/editar con upload de logo

#### Tab Modelos
- Tabla con filtros por marca y categoría
- Crear/editar con selectores de marca + categoría
